This repository contains simple Python programs designed to practice user input, string formatting, and basic arithmetic operations.

Task 1: Perform Basic Mathematical Operations


- Description:  
  A Python script that takes two numbers as input from the user and performs addition, subtraction, multiplication, and division.

- Features:
  - Handles numeric input using `float()`
  - Performs all 4 basic math operations
  - Displays the results clearly with labels

- Output:
  
  Enter the first number: 5
  Enter the second number: 10

  Addition: 15.0
  Subtraction: -5.0
  Multiplication: 50.0
  Division: 0.5


Task 2: Create a Personalized Greeting

- Description:  
  A Python script that asks the user for their first and last names, then displays a personalized greeting using that full name.

- Features:
  - Uses `input()` to get user data
  - Demonstrates use of `f-strings` and `{}` for string formatting

- Output:
  
  Enter your first name: John
  Enter your last name: Doe

  Hello, John Doe! Welcome to the Python program.
